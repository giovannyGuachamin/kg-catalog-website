Privacy Policy

K&G Boutique Automation · Last updated October 14, 2026.

Operator and purpose

K&G Boutique uses this application privately to manage its catalog photographs and information. Contact: kgboutique.contacto@gmail.com.

Access to Google data

The application requests OAuth authorization for Google Drive and Google Sheets. The current permissions allow it to view, create, edit, and delete Drive files and spreadsheets in the authorized account. Its intended use is limited to the folders and spreadsheet configured for the catalog.

Processed data includes photographs, filenames, Drive identifiers and links, product names, SKUs, categories, prices, descriptions, and processing records. The catalog workflow does not require buyer information.

Storage and retention

Photographs and records are stored in the authorized account's Drive and Sheets. The local computer retains photographs, OAuth credentials, tokens, and state records to support operation recovery. Photographs and records are not automatically deleted when processing finishes; the operator manages their retention and deletion.

Data sharing

Images and the catalog data sheet may be made accessible through public links so Meta can import them. Commercial data, identifiers, and necessary processing states may also be transmitted to ChatGPT through MCP tools when the operator uses them. OAuth credentials and tokens are stored locally and are not included in this website's pages or the MCP's intended tool responses.

Access to Google data is used for the catalog functions described here. K&G Boutique does not sell data obtained from Google. The use and transfer of information received from Google APIs will comply with the Google API Services User Data Policy, including its Limited Use requirements.

Control and revocation

The account owner can revoke authorization through their Google account connections. Revocation stops future application access but does not automatically delete existing files, local copies, or products already imported into Meta. The operator must manage deletion in each service and on the local computer. Requests to access, correct, or delete data can be sent to the contact email.

This informational website

These pages contain no forms, sign-in functionality, first-party cookies, or analytics tools added by K&G Boutique. GitHub Pages provides hosting and may process technical information about visits under its privacy statement.

Changes

This policy will be updated when the application's functions or data handling practices change.
